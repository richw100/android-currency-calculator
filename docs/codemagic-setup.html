iOS Build Setup

How to build the iOS app using Codemagic CI/CD — no Mac required.

How it works

The iOS project uses XcodeGen to generate the .xcodeproj from a project.yml spec. Codemagic installs XcodeGen, generates the project, then builds it. You never need Xcode locally — just push code and Codemagic does the rest.

  • ios/project.yml — XcodeGen project spec
  • codemagic.yaml — build pipeline (repo root)
  • ios/CalcApp/ — all Swift source files

Step 1 — Connect Codemagic

One-time setup

  1. Go to codemagic.io and sign up with your GitHub account.
  2. Click Add application and select richw100/android-currency-calculator.
  3. Codemagic will detect codemagic.yaml automatically and list the iOS Debug Build workflow.

Step 2 — Trigger a build

Starting a build

  1. Either push any commit to main, or open the Codemagic dashboard and click Start new build.
  2. Select the iOS Debug Build workflow and click Start build.
  3. The pipeline will:
    • Install XcodeGen via Homebrew
    • Run xcodegen generate inside ios/
    • Build for the iOS Simulator (iPhone 15) with no signing required
  4. You'll receive a build result email at richw999-play@yahoo.com.
No Apple Developer account needed for the simulator build — it compiles and verifies the code without any signing certificates.

Step 3 — Real device / App Store (later)

Once the simulator build passes, distributing to a real device or the App Store requires:

  1. An Apple Developer account ($99/year at developer.apple.com).
  2. A distribution certificate and provisioning profile — generated in Xcode or Apple Developer portal.
  3. Adding the certificate and profile to Codemagic under Teams → Code signing identities.
  4. Updating codemagic.yaml with the signing configuration and switching the build destination from simulator to generic/platform=iOS.

This can be set up when the app is ready for TestFlight or App Store submission.
